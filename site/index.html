02 / Story

How I got here. Built at every step, always for a real domain.

Human-computer interaction

2017 · AHLab, Singapore

At the Augmented Human Lab I learned to start from people, and to read heterogeneous signals from wearables, cameras and the body.

Computer vision

2017 · Singapore

A finger-worn camera that reads labels aloud for people with visual impairments. Built with CNNs, before transformers.

FingerReader 2.0 IMWUT 2018 ↗

Reinforcement learning

2018 · Auckland

Universal successor features let one agent reach new targets in homes it has never seen. They led me into model-free and model-based RL.

VUSFA arXiv 2019 ↗HAUSR NeurIPS 2018 workshop ↗Code GitHub ↗

Self-supervised learning

2020 · PhD, Auckland

Encoders pre-trained without labels, fused across speech, text and vision to learn from very few.

SSL fusion IEEE Access 2020 ↗BERT-like fusion Interspeech 2020 ↗

End-to-end RAG

2021 · PhD, Hugging Face

The successor to RAG. Original RAG froze the passage encoder. RAG-end2end trains both DPR towers with the generator and re-indexes the domain knowledge as it learns.

RAG-end2end TACL 2023 ↗Code Hugging Face ↗

Domain-expert LLMs

2022 · Marigold, Arcee.ai

Continual pre-training and model merging that turn a general LLM into a domain expert, shipped to production.

MergeKit EMNLP 2024 ↗Llama 3 70B SEC data, 2024 ↗

Decentralized pre-training

2026 · Pluralis

Pre-training across GPUs on the open internet. Each holds one stage of the model, and anyone can join.

Agora arXiv 2026 ↗FG-DiLoCo ICML 2026 ↗

Decentralized post-training

2026 · Pluralis

I lead RL post-training on the same open swarm, with compressed links and rewards from real environments.

GPU-mesh adaptation arXiv 2026 ↗ROLL × OpenReward Merged ↗Base to reasoning Blog ↗

Efficient inference

Now

Every layer of the inference stack, from silicon to serving, tuned so big models run fast and locally.

What comes next

Next run · queued

LLMs, wired to the physical layer. Small world models learn how each site behaves and run as a service, so every plan is simulated before anything moves.
